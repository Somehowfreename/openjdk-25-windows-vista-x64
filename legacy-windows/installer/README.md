# Release installer source

This directory contains the NSIS source and PowerShell driver for the three
x64 release installers: Windows XP Professional x64 Edition SP2, Windows Vista
SP2 x64, and Windows 7 SP1 x64.

The XP and Vista inputs must be release images produced by the application-local
compatibility tooling in `legacy-windows/jdkxp`. The Windows 7 input is the
unmodified Eclipse Temurin release documented in `LEGACY_WINDOWS_RELEASE.md`.
NSIS 3.12 is the certified compiler. The build treats all NSIS warnings as
errors, embeds a complete payload SHA-256 manifest, pins the certified payload
source commit from `release-config.psd1`, and refuses a dirty source tree.

```powershell
.\legacy-windows\installer\build-release-installers.ps1 `
  -XpRuntime C:\jdk-images\jdk25-xp-x64 `
  -VistaRuntime C:\jdk-images\jdk25-vista-x64 `
  -Win7Runtime C:\jdk-images\temurin-25.0.4+7 `
  -NsisRoot C:\tools\nsis-3.12 `
  -OutputDirectory C:\release\jdk25
```

The resulting `SHA256SUMS.txt` covers the installer executables. Each installer
also installs its payload manifest as `PAYLOAD-SHA256SUMS.txt`. Installers do
not change `PATH` or `JAVA_HOME`; users select the installed `javaw.exe` in
their launcher.

The per-file payload manifests are deterministic for identical inputs. NSIS
records build-time metadata in the outer executable, so a later rebuild can be
functionally identical without having the same installer hash. Publish the
`SHA256SUMS.txt` generated by the exact binaries being released.
