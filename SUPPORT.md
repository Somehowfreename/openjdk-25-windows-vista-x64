# Support

## Supported in 1.0.0

- Windows XP Professional x64 Edition SP2;
- OpenJDK 25.0.4 installer from this repository;
- official MultiMC 0.7.0-4274;
- official Minecraft Java Edition 26.1, 26.1.1, 26.1.2, and 26.2 Vanilla;
- Minecraft 26.3 Snapshot 9 Vanilla single-player;
- normal Microsoft device-code sign-in and authenticated multiplayer;
- bundled software-renderer path and compatible native XP x64 GPU drivers.

## Not supported in 1.0.0

- Windows XP 32-bit;
- Windows Vista or any other operating system;
- Fabric, NeoForge, Forge, or individual mods;
- Minecraft versions not listed in the release test matrix;
- cracked launchers, copied account data, or redistributed Minecraft assets;
- operating-system security, third-party launcher bugs, or unsupported GPU
  drivers.

The installer never contains, copies, or stores account credentials or tokens.
Users authenticate through MultiMC's normal Microsoft device-code flow and must
legitimately own Minecraft.

Authenticated multiplayer is release-qualified for the main releases from
26.1 through 26.2. Minecraft 26.3 Snapshot 9 multiplayer has not been tested.

When reporting a problem, use the GitHub issue template and include sanitized
logs. Never publish `accounts.json`, authentication tokens, authorization
codes, or account credentials.
