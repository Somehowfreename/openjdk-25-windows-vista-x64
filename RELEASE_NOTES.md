OpenJDK 25.0.4 for Windows Vista SP2 x64, supporting Minecraft 26.1–26.2
single-player, local/LAN servers, and online servers.

Fabric and NeoForge mod-loader support is included for Minecraft 26.1–26.2.
Individual mods have not been tested.

Minecraft 26.3 mod loaders are not supported yet. Snapshot 10 works in vanilla
single-player; multiplayer is expected to work but remains unverified because
no compatible public server was available for testing.

Download the Vista OpenJDK installer below. The Vista certificate installer
is separate; the README also explains how to obtain and import the
certificates manually.
