# Changelog

## 1.0.0

- Initial separate Windows Vista SP2 x64 release of OpenJDK 25.0.4.
- Minecraft 26.1–26.2 single-player, local/LAN servers and online servers.
- Fabric and NeoForge support for Minecraft 26.1–26.2.
- Individual mods have not been tested.
- Minecraft 26.3 Snapshot 10 vanilla single-player. Multiplayer is expected
  but unverified; no compatible public server was available for testing.
- Minecraft 26.3 mod loaders are not supported yet.
